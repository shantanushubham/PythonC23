# What is Django?
Django is a Python-based web framework that allows you to build web applications quickly and easily. It is free and open-source

# Why use Django?
Django is a full-stack web framework, which means that it provides all the tools you need to build a web application from the ground up. It is also very popular, and there is a large community of developers who use it.

# How to install Django?
Django is installed using pip.

# How to create a new project?
Django projects are created using the django-admin command.

# How to create a new app?
Django apps are created using the django-admin command.

# How to run the development server?
Django projects are run using the runserver command.
